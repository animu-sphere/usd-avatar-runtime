# OST reports

Dated records of what using [OpenStrata](https://github.com/animu-sphere/open-strata) (`ost`)
was like in this repository, written as feedback to its maintainers. They are append-only: a
report is not rewritten when a later `ost` changes the result. A newer report verifies the change.

The [evidence log](../evidence-log.md) holds this repository's own measurements. A report cites
them and adds what matters upstream.
